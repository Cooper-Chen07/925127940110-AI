## 使用方式

选择一个版本，将其 `UsrAI.cpp` 和 `UsrAI.h` 成对复制到课程提供的游戏工程。重写系列的已验证基线使用 Qt 5.9.2、MinGW 5.3、标准 Release O2；旧版本保持对应历史接口，不将其他阶段头文件混入。

游戏胜利以祭司成功转换敌方攻城武器厂且引擎判定获胜为准。测试用时按游戏帧计算，墙钟耗时、MAX 测试速度和 10 倍测试速度分别记录。不同源码、不同条件的成绩不合并。
